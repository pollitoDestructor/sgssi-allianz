## Despliegue del proyecto con Docker Compose

### Requisitos previos

#### Docker

Antes de comenzar, hay que asegurarse de tener Docker instalado:

```bash
sudo apt install docker
```

#### Repositorio

Asimismo, se descarga el repositorio con:

```bash
git clone -b entrega_1 https://github.com/pollitoDestructor/sgssi-allianz.git
```

### Ejecutar y detener el proyecto

#### Ejecutarlo

Hay que hacer uso del "docker-compose.yml" con:

```bash
docker-compose up
```

#### Detenerlo

```bash
docker-compose down
```
